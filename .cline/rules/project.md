# Правила проекта

- Используй TypeScript; не добавляй `any` без явного обоснования.
- Предпочитай функциональные React-компоненты и React Hooks.
- Для стилизации используй styled-components, не добавляй Tailwind или CSS-модули без запроса.
- Компоненты должны быть небольшими и переиспользуемыми.
- Перед изменениями сначала кратко опиши план.
- После изменений запускай доступные lint, typecheck и test-команды.
- Не изменяй package.json, зависимости, конфигурацию Next.js или окружение без предварительного объяснения причины.
- Не читай и не отправляй содержимое .env-файлов.
- Для Next.js соблюдай разделение Server Components и Client Components; добавляй "use client" только при необходимости.
